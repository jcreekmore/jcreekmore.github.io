Lately, I have been reading a site called [Good Math, Bad
Math](http://scienceblogs.com/goodmath/). On Fridays, the author posts in his
[Pathological
Programming](http://scienceblogs.com/goodmath/goodmath/programming/pathological_programming/)
category, which is reserved for a description of some very, very strange and
pointless programming languages. [Today's
post](http://scienceblogs.com/goodmath/2007/02/pathological_programming_as_pa_1.php)
tickled me: the programming language is called Chef and programs in it are
written like recipes. The thing that tickled me the most: there is a _serve
with**sub-recipe**_ statement that causes a sous-chef to go off and prepare
the sub-recipe and return the dish to the main chef -- basically, a function
call.
